- 不保证外部 GeoIP 数据库把你的地址标成某个国家。IP 归属地查询结果和机房实际位置可能对不上。
- 不保证某个 IP 永远归你。网络撤出服务时，地址会变，包括官方主动更换。
- 不保证地址在任意网络、任意国家都可达。第三方运营商的路由和封锁不在 JustHost 控制范围内。

这三条不是 JustHost 独有的问题，但写进条款里的商家不多。买之前把它当成前提，比买完发现“换了 IP 还是不通”要省事。

### IP 进了黑名单怎么办

如果你的地址被某个具体服务或黑名单拉黑了，可以开工单说明情况。工程师在特殊情况下能从同地点的另一个子网手工挑一个空闲地址给你，但这不是标准服务，不保证子网，也不承诺处理时限。

手工换是在你的 VPS 内部由代理执行的，所以 SSH 端口必须是开着的。SSH 关着的话流程会中断，报 `PROVISION_VM_AUTH_REJECTED`，剩下的部分得你自己进 VNC 控制台完成。真要走到这一步，先把 SSH 打开。

还有一点容易混：免费换 IP 是换掉当前这个地址，不是额外多给你一个 IP。想再加一个独立 IPv4，属于附加服务，官网标价 ¥22.29/月。加带宽也是单卖的，+10Mbps 是 ¥16.80/月，独享 1Gbps 是 ¥2240.85/月。

## 换完 IP 之后，三件事得自己做

面板显示换了，不等于业务已经恢复。下面三步每次换完都值得走一遍。

**确认新 IP 真的生效。** 在面板看一下当前分配的地址，再登进机器用 `ip a` 或 `curl ifconfig.me` 对一遍。有人的机器缓存了旧地址，面板已经变了，系统里还挂着老的。

**改掉所有依赖旧 IP 的配置。** 代理服务端的监听地址和客户端配置、绑定了域名的 A 记录、防火墙和面板里的 IP 白名单，这些不会自动跟着变。DNS 还有缓存时间，改完别指望立刻全网生效。

**旧地址收不回来。** 换出去就归池子了，没有找回的通道。换之前想清楚这台机器上有没有正在跑的业务会被打断。
